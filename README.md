One funny single-line excuse a developer gives when code breaks in production, under 200 characters: the classic "it worked in staging" defence, turned by spelling out exactly why staging is a fantasy world — polite data, fictional users, servers that have never met a real customer. The joke is a dev recognising their own excuse, and the punch lands on the last clause.

> It worked in staging, where the data is polite, the users are fictional, and the servers have never met a real customer.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–200 characters, one line, not whitespace-only, no control characters) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
